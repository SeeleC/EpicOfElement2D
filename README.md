## 🎮 游戏介绍

### 这是什么？

《元素之诗：灾厄》是一款 **2D 俯视角动作 RPG（ARPG）实验项目**，目标是把一款中小型游戏的**全部内容拆解成可编辑的 JSON 数据包**，从而验证「**改数据即改玩法**」——不写代码也能调整角色数值、增加怪物与装备、配置新配方和任务。

游戏发生在曾遭元素灾厄吞噬的卡兰德大陆。你将从一位初出茅庐的冒险者开始，在村庄周边狩猎野兽、采集矿物与作物、锻造装备、调配药水、完成任务，逐步揭开灾厄的真相。

### 核心玩法

| 玩法模块 | 说明 |
| -------- | ---- |
| 🗺️ 探索 | 程序化生成的无限世界（按 16×16 区块仅保存已访问部分），含草原/林地/岩地/雪原生物群系 |
| ⚔️ 战斗 | 走位 + 5 个技能 + 资源管理（架势 / 法力），受击有硬直、击退、浮空、减速等状态 |
| 🎣 采集 | 树木/矿脉/作物三系采集工具，随等级提升可采集更高品阶资源 |
| ⚙️ 制作 | **炼药锅**（炼药/烹饪，重材料数量）与**铁匠铺**（锻造装备，重消耗金币与材料） |
| 🎒 装备 | 五大槽位（头/身/主手/副手/饰品），穿戴即获得属性加成 |
| 📙 任务 | 多目标任务（击杀 + 采集等），完成自动结算经验与奖励 |
| 💾 存档 | 3 个存档位，玩家数据与「区块世界」分文件持久化 |

### 四大职业

| 职业 | 定位 | 资源 | 特点 |
| ---- | ---- | ---- | ---- |
| ⚔️ 剑士 | 近战输出/前排 | 架势 | 独特【招架】机制（空格），格挡成功后强化技能 |
| 🛡️ 骑士 | 坦克/前排 | 架势 | 高血高减防，技能带仇恨/减益，大招无敌 |
| 🔮 法师 | 远程AOE/辅助 | 法力 | 火球爆炸、暴风雪减速、治愈之光，控制多样 |
| 🏹 游侠 | 远程输出C位 | 法力 | 破防减益 + 翻滚机动，单体/范围兼顾 |

## 📖 新手教程

下面按**实际操作顺序**带你完成第一个冒险循环：**出门 → 打怪 → 捡装 → 采集 → 任务 → 锻造 → 存档**。

### 第 0 步：启动与选职业

1. 启动后用 **鼠标左键** 点击主菜单 **「新游戏」**；
2. 在职业选择界面，用鼠标 **上滑/点选** 查看职业说明，点击 **剑士 / 骑士 / 法师 / 游侠** 之一开始；
   - 第一次玩推荐 **剑士**（均衡、有招架保命）或 **游侠**（远程、不易被近身）。
3. 进入游戏后你会出生在村庄空地，周围有野猪、岩脊兽与 NPC。

### 第 1 步：移动与视角

- 按住 **W / A / S / D**（或方向键）移动角色；
- 鼠标移动控制**瞄准方向**，屏幕中心是你的朝向前方；
- 摄像头会平滑跟随你，无需手动滚屏。

### 第 2 步：打第一只怪

1. 靠近野猪（画面中的红色块状生物）；
2. 按 **J** 施放你的 **技能 1**：
   - 剑士 → 【横一字斩】（近战横扫）
   - 法师 → 【火球术】（远程弹体，命中爆炸）
   - 游侠 → 【多重射击】（前方一排箭）
3. 怪物死亡后，会在地上掉落 **金币 / 皮革 / 兽牙** 等，也有概率掉装备或药水；
4. 掉落物会自动拾取进背包（也可按 **E** 手动靠近拾取）。
5. 击杀获得 **经验（EXP）**，屏幕左上经验条满后自动**升级**。

> 💡 被打受伤时画面会泛红并带硬直，先拉开距离等受击恢复再回头输出。血量不足时按 **1** 喝血药。

### 第 3 步：与 NPC 对话、接任务

1. 走向村庄中戴蓝色/发包块的 NPC，头顶出现 **[E] 与 XX 交谈** 提示；
2. 按 **E** 打开对话框（显示于屏幕底部），再按 **E** 关闭；
3. 与「任务发布员」对话并接受 **「初探卡兰德」** 主线任务后，它会在你的任务后台记录：
   - 目标：**击杀 3 只岩脊兽** + **采集 2 块岩钢**；
   - 当前进度在打开背包（B）时可看到（本版本的背包会优先显示装备栏，任务进度见 `player.quests`）。

### 第 4 步：采集与制作

1. 找到地面上带名称的草/木/矿石（如 **白桦木、铁矿、麦子**）；
2. 按 **E** 交互采集，获得木材 / 矿石 / 作物；
   - 需要对应**采集工具**（斧/镐/镰）与足够 **采集熟练度** 才能采到高品资源。
3. 打开背包 **B**，确认你已捡到 **铁矿/铁锭** 与足够 **金币**；
4. 本次演示的锻造配方（见 `content/recipes.json`）：
   - **锻造-木剑**：消耗 `铁木×4` + `金币×10` → 木剑（可穿戴）；
   - **锻造-生锈铁剑**：消耗 `铁锭×3` + `金币×60` → 铁剑（可穿戴）；
   - 炼药（炼药锅）：`甜香草×1 + 水×2 → 小回复药水×8`（成功率 90%）；
   - 烹饪：`野猪肉×1 → 烤野猪肉×2`。

> 🔁 核心循环：**打怪 → 掉材料/金币 → 采集 → 锻造/炼药 → 变强 → 打更强的怪**。

### 第 5 步：装备与背包

- 按 **B**（或 C）打开背包；
- 背包左侧是物品栏（6×4 共 24 格），右侧是装备栏（头/身/主手/副手/饰品）；
- 若背包/拾取到了可穿戴装备，在背包界面按 **Q** 会自动穿戴/卸下第一件装备；
- 装备会即时改变你的血限/攻防等结算属性（可看 HUD 变化）。

### 第 6 步：技能释放

左上角技能栏显示你的 5 个技能槽：

| 按键 | 剑士 | 骑士 | 法师 | 游侠 |
| ---- | ---- | ---- | ---- | ---- |
| **J** | 横一字斩 | 牵制斩 | 火球术 | 多重射击 |
| **K** | 上撩斩 | 里拳攻击 | 冰枪术 | 后跃射击 |
| **U** | 重劈 | 回旋斩 | 治愈之光 | 风之刃 |
| **I** | 破军 | 突进强槌 | 水柱术 | 连珠箭 |
| **O** | 回斩 | 战吼 | 雷爆术 | 穿裂箭 |

> 大多数技能消耗 **架势/法力**；资源不足时技能无法释放（可等待自动回复或喝蓝药）。
> 空格键：翻滚闪避；部分职业（剑士/骑士）空格即招架/格挡姿态。

### 第 7 步：暂停与存档

- 按 **ESC** 打开暂停菜单：
  - **继续游戏** —— 回到战斗；
  - **保存游戏** —— 立即写入当前存档位；
  - **保存并回主菜单** —— 保存后回到标题界面。
- 存档存放在 `saves/slot1~3/`，包含 `world.json`（区块世界）+ `save.json`（玩家）+ `meta.json`（摘要）。
- 下次启动在标题界面选 **「继续游戏 (载入)」**，选择对应存档位即可继续。

## 🧩 设计要点

### 1. 数据驱动（content/*.json）
- **注册中心 `REGISTRY`**：分类加载所有内容，任意系统按 id 查询。
- 数值（伤害、冷却、掉落率、物价、血量）集中在 JSON，改数据即改玩法。
- 新增物品 / 技能 / 怪物只需加一个 JSON 条目，无需改引擎代码。

### 2. 存档模式 ≈ Minecraft
- 世界被划分为 **16×16 的区块(Chunk)**，区块按需生成、按区块序列化。
- 只有玩家访问过的区块会被保存 → 无限 / 大世界扩展 + 存档轻量。
- 玩家数据（等级 / 职业 / 背包 / 装备 / 任务）与区块世界分离存档。

### 3. 四大基础职业
- **剑士**：均衡前排，独特【招架】姿态（空格）抵挡伤害并强化技能，资源为「架势」。
- **骑士**：坦克，高血高减伤，技能带仇恨 / 减益，大招可免疫致命一击，资源为「架势」。
- **法师**：远程 AOE / 辅助，火球爆炸、暴风雪减速、治愈之光，资源为「法力」。
- **游侠**：远程输出 C 位，多重射击、穿裂箭、标记易损，资源为「法力」。

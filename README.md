## 🚀 启动说明（README）

```
项目结构（交付完毕，可直接运行）
├─ main.py            # 入口：python main.py
├─ config.py          # 全局配置 / 键位 / 职业 / 公式 / 字体
├─ utils.py           # 工具（计时器 / 文字 / 混入类）
├─ data/              # 数据层（物品/技能/怪物/NPC/任务/地图）
├─ entities/          # 实体层（玩家/敌人/NPC/投射物）
├─ systems/           # 系统层（战斗/背包/装备/加点/任务/对话/商店/设置）
├─ ui/                # 界面层（HUD/背包/角色/任务/对话/商店/菜单）
├─ scene.py           # 场景（地图+实体+系统+UI 的装配与运行）
├─ particles.py       # 粒子系统
├─ sound.py           # 程序合成音效
├─ save.py            # 三存档位 JSON 持久化
└─ requirements.txt   # pygame
```

**运行方式**

```bash
pip install -r requirements.txt
python main.py
```

**游戏流程**

1. 标题 → 选职业（魔剑士 / 元素法师 / 风射手 / 暗影刺客）→ 选存档位；
2. 主城找 `quest_npc` 接主线 → 传送门（按 E）进入 4 层地下城；
3. 打怪掉宝（金币/装备/药水）→ 找铁匠买卖装备、炼金师买药水；
4. 升到 20 级 → 击败深渊魔殿首领 → 通关！

**操作**（可在 设置 中自由改键）

| 按键  | 功能               | 按键        | 功能                 |
| ----- | ------------------ | ----------- | -------------------- |
| A / D | 左右移动           | J           | 普攻（三段连击）     |
| 空格  | 跳跃               | K           | 闪避（后跳，无敌帧） |
| S     | 下蹲               | U I O P L ; | 技能 1~6             |
| E     | 交互 / 对话 / 传送 | B           | 背包                 |
| 1~4   | 药水快捷栏         | C / Q       | 角色面板 / 任务面板  |
| Esc   | 暂停 / 关闭窗口    |             |                      |
